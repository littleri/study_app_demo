# 首页教材工作区重构实施计划

## 1. 文档目的

本文档将已确认的首页改造方向拆分为可独立实施、可验证、可回退的阶段，并记录每个阶段的审核结果。执行规则如下：

1. 每个阶段由一个有明确文件责任范围的 subagent 实施。
2. subagent 完成后停止，不自动进入下一阶段。
3. 主代理检查代码差异、运行相关测试并进行必要的浏览器视觉审核。
4. 只有审核通过后，才更新本文档状态并启动下一阶段。
5. 不覆盖或回退用户已有的无关工作区改动。

## 2. 已确认的产品与视觉约束

- 首页以“当前选中的教材”为唯一书本上下文。
- 教材采用横向居中吸附选择器；左右教材需要保持可发现，但所有未选中教材封面必须虚化。
- 虚化只作用于封面视觉，不缩小真实触控范围，也不作为唯一的选中状态提示。
- “继续学习”“回到原书”、当前章节信息和本章工具全部放入“这本书的下一步”工作区。
- 本章工具不再使用首页原来的四个简化图标入口。
- 工具卡必须复用学习页章节工具的内容结构和视觉语言：作业诊断题目预览、闪卡预览、未来工具占位、底部图标/标题/说明/箭头。
- “继续学习”和“回到原书”必须是两个不同的导航语义；不能机械复用学习页当前的 `source` 工具行为。
- 作业诊断和闪卡复习必须在跳转前设置与首页展示一致的章节 ID。
- 视觉继续沿用当前前端的浅灰蓝背景、白色表面、深色文字、蓝紫主操作、薄线 Lucide 图标和克制阴影。
- 桌面与移动端保持同一信息架构；移动端优先，主要验收设备为 iPhone 竖屏。

## 3. 目标信息架构

```text
首页头部
└── 问候语 / 教材状态

我的教材
└── 横向教材选择器
    ├── 未选中封面：虚化、降饱和、降低透明度
    └── 选中封面：清晰、居中、显示书名和进度

这本书的下一步
├── 当前章节 / 页码 / 上次学习位置
├── 继续学习
├── 回到原书
└── 本章学习工具
    ├── 作业诊断
    ├── 闪卡复习
    └── 更多功能占位

全局区域
├── 今日待办
├── 学习计划
├── 错题复习
└── 上传或其他教材状态
```

## 4. 关键状态规则

| 教材状态 | 选中封面 | 下一步工作区 | 章节工具 |
|---|---|---|---|
| `ready` | 清晰 | 章节、继续学习、回到原书 | 启用 |
| `needs_review` | 清晰 | 确认目录、对照原书 | 不显示 |
| `processing` | 清晰 | 解析进度和后台说明 | 不显示 |
| `uploaded` | 清晰 | 开始解析 | 不显示 |
| `error` | 清晰 | 错误恢复和原文件入口 | 不显示 |
| 教材切换加载中 | 清晰 | 与新教材匹配的骨架 | 骨架且不可点击 |
| 教材切换失败 | 恢复上一教材 | 内联错误与重试 | 不显示 |
| 空教材列表 | 无轮播 | 上传第一本教材 | 不显示 |

### 4.1 视觉选择与已加载教材必须分离

首页不能把轮播中心位置直接当作“课程资源已经加载完成”。实现中至少区分：

- `selectedBookId`：轮播当前视觉上下文，可以指向任意状态的教材。
- `loadedBookId`：已经完整加载章节、计划、课程、闪卡等学习资源的教材。
- `pendingBookId`：正在请求完整学习资源的候选教材。

只有 `ready` 或确实需要目录资源的教材才调用完整课程加载。`processing`、`uploaded`、`error` 和未知状态优先使用 `CourseSummary` 与 `parse_job_*` 渲染轻量状态工作区，不调用完整 `selectCourse`。

### 4.2 状态规范化与优先级

新增可测试的首页教材模型构建函数，集中完成：

1. 当前本地教材与远端 `courseSummaries` 去重。
2. 当前本地 parse job 状态优先于旧的远端摘要状态。
3. `parse_job_status=failed` 规范化为首页 `error`。
4. 未识别的 `CourseSummary.status` 安全回退到“等待准备”，不显示章节工具。
5. 列表刷新后选中教材被删除时，回退到已加载教材或第一本可用教材。
6. 保持教材顺序稳定，不因状态刷新发生不必要跳位。

## 5. 教材虚化规范

### 选中教材

- `filter: none`
- `opacity: 1`
- 视觉缩放约 `1`
- 明确的位置计数与文本选中状态
- `aria-selected="true"`

### 相邻未选中教材

- 建议 `blur(2px)`
- 建议 `saturate(.7)`
- 建议 `opacity: .6`
- 建议视觉缩放约 `.9`
- 只虚化封面图片，不虚化按钮语义、焦点轮廓或无障碍文本

### 远处教材

- 可提高到 `blur(3px)`
- `opacity` 可降到约 `.38`
- 不持续渲染不必要的高分辨率封面

### 切换时机

- 横滑过程中不连续重算整页内容。
- 滚动吸附结束后确认中心教材。
- 新教材立即成为视觉选中项，下方工作区进入匹配的新教材加载状态。
- 数据加载成功后原子更新工作区；失败时恢复上一已加载教材。
- 过渡以 `180–220ms` 为目标，并支持 `prefers-reduced-motion`。

## 6. 组件目标

### 新的共享章节工具组件

建议组件边界：

```text
ChapterToolCards
├── AssignmentToolCard
├── FlashcardToolCard
└── FutureToolCard
```

要求：

- 工具定义继续以 `src/screens/studyTools.ts` 为单一数据源。
- 学习页和首页共同消费共享组件。
- 视觉组件不内置页面导航；页面通过回调决定路由。
- 工具卡共享 CSS 从 `study.css` 中抽离，避免复制近似样式。
- 抽取后学习页视觉和既有行为不得回归。

### 新的教材选择器

建议组件边界：

```text
HomeBookCarousel
├── BookCoverOption
├── PositionIndicator
└── Loading / Empty 状态
```

要求：

- 使用 `courseSummaries` 和当前本地教材构建稳定列表。
- 当前 `sourcePageImageUrl` 对所有教材只返回同一张演示图片，不能直接作为多教材封面能力。
- 第一阶段实现采用“基于书名/文件类型的稳定差异化封面回退”，保证多本教材可区分；若后端真实第一页图片接口可用，再以真实图片优先、稳定回退兜底。
- 支持点按、横滑、键盘方向键和屏幕阅读器。
- 支持 0、1、2、多本教材和长书名。
- 第一和最后一本教材也能居中。

### 新的选中教材工作区

建议组件边界：

```text
SelectedBookWorkspace
├── ReadyBookWorkspace
│   ├── ResumeSummary
│   ├── ContinueAction
│   ├── SourceAction
│   └── ChapterToolCards
├── ProcessingBookWorkspace
├── ReviewBookWorkspace
├── ErrorBookWorkspace
└── LoadingBookWorkspace
```

## 9. 最终验收标准

- 用户能在三秒内识别当前选中的教材和下一步学习动作。
- 所有未选中教材封面处于虚化状态，当前教材完全清晰。
- 横滑、点按和键盘操作均能切换教材。
- 横滑结束前不频繁重绘下方工作区。
- 教材切换期间不会保留上一教材的可点击动作。
- “本章学习工具”位于“这本书的下一步”内部。
- 首页与学习页使用同一个章节工具卡组件和同一份共享样式。
- 作业诊断保留题目预览；闪卡复习保留卡片预览；更多功能保持禁用占位。
- “继续学习”和“回到原书”导航目标明确且不同。
- 作业诊断与闪卡使用正确的选中章节 ID。
- `ready`、`processing`、`needs_review`、`uploaded`、`error`、加载、失败和空状态均有覆盖。
- 主要触控目标不小于 44×44px。
- 状态不只依赖颜色或虚化表达。
- `prefers-reduced-motion` 下仍能正确理解和操作。
- iPhone 竖屏、窄屏、平板和桌面均无内容溢出或遮挡。
- Lint、测试和生产构建通过。
