# Demo 前端新增功能清单

> 对照仓库：[AdjacentGarden/LLM_Study_App](https://github.com/AdjacentGarden/LLM_Study_App)  
> 对照基线：主仓库 `b5af3a5` 与当前视频演示 Demo  
> 更新时间：2026-09-29

## 文档目的

本清单记录主仓库相对当前 Demo 已具备、而 Demo 尚未完整展示的前端能力。当前 Demo 的目标是稳定拍摄演示视频，因此只要求前端流程真实、可重复运行；后端 OCR、ASR、RAG、账号和云同步可使用本地夹具或确定性状态机替代。

本期只实现两项 P0 能力：

- 直接批注教材原页的手写笔记。
- 真实录音、逐字稿确认与教材整理版的语音笔记。

其余条目仅作为产品 Backlog，不属于本期实施范围。

## 本期手写笔记范围

- Android 平板竖屏为主要画幅。
- 在已发布教材原页上叠加矢量笔迹，不制作独立无限白板。
- 支持钢笔、荧光笔、整笔擦除、颜色、粗细、撤销、重做、手指书写开关和自动保存。
- 触控笔始终书写；默认由手指平移或缩放，开启“手指书写”后单指书写、双指缩放。
- 笔迹使用教材原图归一化坐标保存，缩放、旋转和重新打开后仍与原文对齐。
- “完成并整理”通过本地确定性阶段展示保存、识别、核对、教材检索、整理与复核。
- 原始笔迹、识别文字和整理版分别保留；继续修改笔迹会让旧整理版变为历史版本。
- 没有已发布教材页图时禁用批注，但仍可创建文字或语音笔记。

## 本期语音笔记范围

- 在 Android WebView 中真实申请麦克风权限并录音。
- 使用 `MediaRecorder` 保存音频，使用 Web Audio `AnalyserNode` 显示真实音量波形。
- 支持录音、暂停、继续、结束、回放、重新录制和后台中断恢复。
- 单条最长 10 分钟、最大 20MB。
- 每次演示转写后都进入可编辑的逐字稿确认步骤；转写、教材检索和整理使用本地确定性夹具。
- 原始录音、确认逐字稿、教材证据和整理版分别保留。
- 权限拒绝时提供重新尝试、Android 设置提示和示例录音兜底。

## 本期明确不做

- 真实 OCR、手写识别、ASR、RAG 或文本模型调用。
- 云端同步、跨设备恢复和多用户隔离。
- 社区发布、好友分享或多人协作批注。
- 音频文件导入和服务端格式校验。
- 把手写图层或音频附件导入 PDF。
- Android 手机、iOS 或桌面端的正式验收。

## 演示验收原则

- 所有输入控件真实可交互，AI 阶段使用固定时间和固定数据，整个流程不依赖网络。
- 刷新或重启 Android 应用后，已保存的笔迹、录音、逐字稿和整理版仍可恢复。
- 所有教材锚点都能回到对应教材、章节和页码。
- 不增加第五项底部导航；入口只出现在教材选文、原文阅读、章节工具和学习笔记工作台。
- 原始用户内容永远不被模拟 AI 整理结果覆盖。
