# 课程与资料

课程是用户的学习空间。一门课程包含多个资料，每份资料有独立的 `bookId`、章节、原文页和学习任务。前端 `Course.id` 与资料 `bookId` 无关，后端或示例仓库返回的是 `CourseSourceSummary`，通过 `listSources()` 读取。

学习页的「当前课程」切换整个课程；「添加资料」上传文件或关联已有教材。新增课程通过独立的创建流程填写名称与学习偏好。首页、课程列表和个人页都列出父课程。目录按资料分组，打开学习工具前会加载对应资料，不将两个文件的页码或章节合并成同一个文件。

本地文件保存在原有 IndexedDB `bookcourse-learning-resources` 中。文件通过 SHA-256 比对内容，重复添加相同内容会复用文件引用，文件同名但内容不同会成为不同资料。整理结果保存在 `bookcourse-local-sources` 中，PDF、DOCX、PPTX、XLSX 和文本读取自身内容，图片和无文字扫描 PDF 保留可阅读的原页。没有可提取文字时不会生成虚构原文或引用。解析错误仍保留原文件，可下载或重新整理。

课程状态保存在 `bookcourse.courses.v2`。首次加载从旧的 `bookcourse.learning-sets.v1` 升级：保留课程 ID、名称、学习偏好、草稿答案、解析任务和本地文件 ID，将旧 `course:<bookId>` 引用转成 `source:<bookId>`。旧状态保留为备份；新状态损坏或不可写时仍可读取旧状态。未归属课程的原教材创建一个课程入口，已关联资料不会再次创建入口。

阅读位置保存为 `<courseId>::<bookId>`，首次恢复仍兼容旧的单独 `bookId` 键。课程内 AI 问答传递 `course_id` 与 `book_ids`，检索范围覆盖课程资料。引用携带其真实 `book_id`，点击时加载正确的资料。笔记的新锚点包含 `courseId`，旧笔记仍按书籍归属课程显示。

移出资料只解除课程关联；移除课程也不删除原文件、解析结果或笔记。移出当前资料后恢复课程中另一份可用资料。原教材的自动课程入口被用户移除后记录在 `dismissedSourceIds` 中，刷新不会重新创建。

验证涵盖状态迁移与损坏回退、课程与资料身份、跨文件进度、独立文件解析、原 PDF 页面渲染、重复文件、失败重试入口、课程创建和阅读位置恢复。多资料 AI 测试验证同页码引用仍按文件区分，点击引用会打开真实文件。刷新后会恢复中断的整理任务，并优先使用已保存的解析结果。关键浏览器测试位于 `e2e/courses.spec.ts`。
