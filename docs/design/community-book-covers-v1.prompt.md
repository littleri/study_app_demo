# 社区书籍封面 V1 提示词

生成方式：Codex 内置 ImageGen（非 CLI），每张封面独立生成。

用途：BookCourse AI 社区页内部 Demo 的数学、物理书籍卡片。图片是 AI 生成的社区课程封面，不是教材扫描件、出版社封面或 MinerU 抽取图。

## 数学｜函数与导数

应用产物：`public/assets/community/functions-derivatives-cover-v1.webp`（ImageGen PNG 输出经 768 × 1024、quality 84 的 WebP 优化）

```text
Use case: scientific-educational
Asset type: portrait cover artwork for a high-school mathematics course card inside the BookCourse AI mobile community page
Primary request: create a clean 3:4 portrait educational cover image representing functions and derivatives.
Subject: one precise coordinate plane with a smooth parabola, a tangent line touching the curve, and a few restrained mathematical construction marks.
Style/medium: polished editorial textbook-cover illustration, flat vector-like geometry rendered as a high-quality raster image.
Composition/framing: centered vertical cover composition, strong readable silhouette at small mobile-card size, generous edge padding.
Color palette: solid deep blue, sky blue, white, and a small restrained purple accent; no UI chrome.
Text: none.
Constraints: scientifically plausible graph; no people; no logos; no publisher marks; no watermark; no recognizable copyrighted cover; no border frame; no app UI; no mockup perspective.
Avoid: Chinese or English letters, equations, random glyphs, gradients used as the main design device, glossy 3D effects, busy detail, shadows outside the cover.
```
